# Security and launch requirements

This repository is currently public. Never commit API keys, customer resumes, or personal information.

Before enabling purchases: configure a private database, secure authenticated order access, Stripe server-side Checkout and signature-verified webhooks, rate limiting, privacy/retention policy, secure upload validation, and failure/retry handling. Do not send customer data to AI services without informed disclosure and appropriate consent. Do not claim a human reviewed output unless a human actually did. Verify output for invented facts.

The order page is an offline demo only and does not submit data.
